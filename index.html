What this app does

MYORYEONG RADIO creates and manages scheduled YouTube Live broadcasts for the authorized channel. It can create a live broadcast, connect an existing YouTube live stream, start local broadcast encoding, and complete the broadcast at the scheduled end time.

This service is not an open public platform and does not offer public account registration.

Google / YouTube API use

The app uses YouTube API Services only after the channel owner grants Google OAuth permission. Access is used for live-broadcast management on the authorized YouTube channel. OAuth credentials and tokens are stored on the operator's own broadcast computer and are not sold or used for advertising.
