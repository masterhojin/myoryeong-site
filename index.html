MYORYEONG RADIO

A private YouTube Live broadcast management tool for scheduled music streams.

About

MYORYEONG RADIO helps an authorized channel owner create, connect, manage, and complete scheduled YouTube Live broadcasts.

This is a private operational tool. It does not provide public account registration or a public user service.

Google and YouTube API use

The application uses YouTube API Services only after the channel owner grants Google OAuth permission. Access is used only for live-broadcast management on the authorized YouTube channel.
