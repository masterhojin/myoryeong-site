Privacy Policy

Last updated: September 20, 2026

MYORYEONG RADIO is a private YouTube Live broadcast management tool that uses YouTube API Services. This policy explains how Google and YouTube account permissions and related data are used.

1. Information accessed

  • YouTube account and channel permissions authorized through Google OAuth.
  • API data required to create, view, bind, manage, and complete YouTube Live broadcasts.
  • OAuth access tokens and refresh tokens required for authorized operation.

2. Purpose of use

The data is used only to manage scheduled live broadcasts for the authorized YouTube channel, including creating broadcasts, connecting live streams, checking broadcast state, and completing broadcasts.

3. Storage

OAuth client configuration and authorization tokens are stored on the operator's own broadcast computer. MYORYEONG RADIO does not use authorized Google or YouTube data for advertising, sale, or profiling.

4. Sharing

Authorized user data is not sold or voluntarily shared with third parties. Data is transmitted to Google and YouTube only as required for the requested API operations.

5. User control and deletion

Access can be revoked at any time from the connected-app or security settings of the relevant Google account. Locally stored OAuth tokens can also be deleted from the broadcast computer.

6. Security

Authentication data is stored locally with restricted file permissions where supported, and Google OAuth and YouTube API communications use HTTPS.

7. Related policies

  • YouTube Terms of Service
  • Google Privacy Policy
  • YouTube API Services Terms of Service

8. Contact

Privacy and OAuth-related inquiries can be sent to the support contact shown on the Google OAuth consent screen.
