개인정보처리방침

Privacy Policy · Last updated: 2026-09-20

MYORYEONG RADIO는 개인용 YouTube Live 자동화 도구이며 YouTube API Services를 사용합니다. 이 정책은 앱이 Google/YouTube 계정 권한과 데이터를 어떻게 사용하는지 설명합니다.

1. 접근하는 정보

  • Google OAuth를 통해 사용자가 허용한 YouTube 계정 및 채널 권한
  • YouTube Live 방송 생성, 조회, 연결 및 종료에 필요한 API 데이터
  • 앱 동작에 필요한 OAuth access token 및 refresh token

2. 이용 목적

승인된 YouTube 채널에서 예약 라이브 방송을 생성하고, 기존 라이브 스트림을 연결하며, 방송 상태를 관리하고, 예약 종료 시 방송을 완료하기 위해 사용합니다.

3. 저장 및 보관

OAuth 클라이언트 설정과 인증 토큰은 방송 운영자가 관리하는 로컬 컴퓨터에 저장됩니다. MYORYEONG RADIO 운영 목적 외의 광고, 판매, 프로파일링을 위해 사용자 데이터를 사용하지 않습니다.

4. 공유

서비스 동작에 필요한 Google/YouTube API 통신을 제외하고 승인된 사용자 데이터를 제3자에게 판매하거나 임의로 공유하지 않습니다.

5. 사용자 통제 및 삭제

사용자는 언제든 Google 계정의 보안/연결된 앱 설정에서 MYORYEONG RADIO의 접근 권한을 취소할 수 있습니다. 로컬 방송 컴퓨터의 OAuth 토큰 파일을 삭제하면 저장된 인증정보도 제거할 수 있습니다.

6. 보안

인증정보는 로컬 환경에서 제한된 파일 권한으로 관리하며, 전송 시 Google/YouTube의 HTTPS OAuth/API 연결을 사용합니다.

7. 관련 정책

  • YouTube Terms of Service
  • Google Privacy Policy
  • YouTube API Services Terms of Service

8. 문의

개인정보 및 OAuth 접근 관련 문의는 Google OAuth 동의 화면에 표시된 앱 지원 연락처를 통해 접수할 수 있습니다.
